# PharmaCalc v1.0
Guia de bolso PK/PD para farmacêuticos hospitalares.
Desenvolvido por Alan Steihogen.

## Como publicar (GitHub Pages)
1. Crie conta em github.com
2. Novo repositório público: `pharmacalc`
3. Upload de todos os arquivos desta pasta
4. Settings → Pages → Branch main → Save
5. Acesse: https://SEU_USUARIO.github.io/pharmacalc/
